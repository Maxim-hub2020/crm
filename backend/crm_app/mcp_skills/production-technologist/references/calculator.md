# Расчёт изделий в CEH CRM

## Последовательность

1. Вызови `crm_calculator_catalog` перед каждым новым расчётом. Каталог и цены могут меняться; не используй идентификаторы из памяти или другого проекта.
2. Определи тип изделия: `shower` для душевой или `mirror` для зеркала.
3. Сопоставь слова пользователя с названиями из каталога. Если совпадение неоднозначно, покажи короткий список подходящих вариантов и попроси выбрать.
4. Спроси только параметры, без которых расчёт невозможен. Не заставляй пользователя повторять уже названные размеры, материал, услуги или доставку.
5. Вызови `crm_calculate_product` и сообщи: выбранную конфигурацию, стоимость изделия, доставку и общий итог. Отдельно напомни, что это предварительная цена до контрольного замера.

## Душевая

Передай в `configuration`:

- `constructionId` — точный идентификатор конструкции из `shower.constructions`;
- `dimensions` — объект со всеми ключами полей выбранной конструкции, например `HEIGHT_0` и `WIDTH_0`;
- `glassId`, `hardwareId`, `hardwareClassId` — точные идентификаторы из каталога;
- `installation` — включать ли монтаж;
- `designerEnabled`, `discountEnabled`, `discountPercent` — только когда пользователь явно задал соответствующий параметр.

Количество и названия размерных полей бери из `fields` выбранной конструкции. Не своди несколько ширин к одной и не используй номинальный размер вместо отсутствующего замера.

## Зеркало

Передай в `configuration`:

- `width` и `height` в миллиметрах;
- `materialId` — точный идентификатор материала из каталога;
- `options` — список выбранных услуг в виде `{ "serviceId": "...", "quantity": 1 }`.

Не добавляй монтаж, подсветку, обработку, вырезы или другие услуги, если пользователь их не указал. Если пользователь назвал услугу, которой нет в каталоге, сообщи это и не заменяй её другой.

## Доставка

- Без доставки: `{ "enabled": false, "zone": "inside", "km": 0 }`.
- По Ростову-на-Дону: `{ "enabled": true, "zone": "inside", "km": 0 }`.
- За город: `{ "enabled": true, "zone": "outside", "km": <расстояние> }`.

Если для доставки за город не указано расстояние, сначала уточни километры. Не определяй расстояние по адресу приблизительно.

## Границы действия

`crm_calculate_product` только рассчитывает стоимость и ничего не сохраняет. Не утверждай, что КП создано, проект обновлён или сумма записана.

Чтобы сохранить результат в существующий проект:

1. Определи проект через `crm_resolve_project` и возьми текущую стоимость из карточки.
2. Покажи пользователю проект, состав расчёта, старую стоимость и новый итог.
3. Получи явное подтверждение сохранения.
4. Вызови `crm_save_calculator_quote` с теми же `product`, `configuration` и `delivery`, передай `project_query` и `confirm=true`.
5. Сообщи номер сохранённого КП и новую стоимость проекта только после успешного ответа инструмента.

Не вызывай сохранение повторно после неопределённого сетевого сбоя: сначала перечитай проект и проверь связанное КП, чтобы не создать дубль.

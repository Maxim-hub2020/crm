# Серверный технолог CEH CRM

Это только указатель подключения. Локальных производственных правил здесь нет.

Единственный рабочий навык: `root@93.183.82.177:/opt/ceh-production-skills/production-technologist/SKILL.md`.

Перед работой прочитай актуальный навык с сервера через MCP `skills/list` и `resources/read`, URI `skill://crm-production/production-technologist/SKILL.md`. Справочники читай тем же способом по ссылкам серверного SKILL.md.

Если эти методы не доступны в текущем клиенте, используй SSH-чтение непосредственно серверных файлов: `ssh -i C:/Users/maxim/.ssh/crm_timeweb_deploy_key -o BatchMode=yes root@93.183.82.177 "cat /opt/ceh-production-skills/production-technologist/SKILL.md"`. Для справочников используй тот же серверный каталог, не локальные пути.

Применяй и изменяй производственные правила только на сервере. Правки выполняй непосредственно в указанной папке и сохраняй коммитом в серверном репозитории `/opt/ceh-production-skills`. Не создавай рабочие локальные копии и не используй прежние версии из плагинов, репозитория приложения или образа CRM. При недоступном сервере сообщи о недоступности актуального навыка.

# Пробная установка на iPhone с Windows

Файл CEH-CRM-unsigned.ipa собирается для настоящего iPhone (arm64), но не подписан.
Его нельзя установить просто открыв ссылку в Safari. AltStore/AltServer подписывает
его локально под вашим Apple Account. App Store Connect и одобрение публикации
для этой пробной установки не используются.

## Установка

1. Следуйте официальной инструкции AltStore для Windows:
   https://github.com/altstoreio/FAQ/blob/main/altstore-world/how-to-install-altstore-windows.md
   Используйте только официальные ссылки. Если уже есть iCloud из Microsoft Store,
   сначала изучите указанную в инструкции альтернативу; не удаляйте его автоматически.
2. Установите AltServer и необходимые компоненты Apple по инструкции.
3. Подключите разблокированный iPhone кабелем USB, подтвердите доверие компьютеру.
4. Через значок AltServer выберите Install AltStore и свой iPhone.
   Apple Account, пароль и коды вводите самостоятельно только в установленном инструменте.
   Это стороннее приложение: ознакомьтесь с его правилами обработки учётных данных.
   Не отправляйте пароль в чат и не добавляйте его в GitHub Secrets.
5. На iPhone подтвердите доверие профилю своего разработчика в основных настройках
   управления устройством. Включите режим разработчика в разделе конфиденциальности
   и безопасности, перезагрузите телефон и подтвердите включение.
6. Передайте CEH-CRM-unsigned.ipa в приложение «Файлы» на iPhone, например через
   собственный iCloud Drive. В AltStore: My Apps / + / выберите этот IPA.
   Компьютер с AltServer должен оставаться доступным, по USB или согласно настройкам Wi-Fi.
7. Откройте CEH CRM и войдите своим обычным аккаунтом CRM. Проверьте LiDAR в замере.

## Срок и данные

При бесплатной подписи срок профиля составляет 7 дней с выдачи, не со скачивания IPA.
До истечения обновите подпись в AltStore через Refresh All с доступным AltServer.
При истечении приложение перестанет запускаться, пока подпись не будет обновлена.
Не удаляйте приложение при проблемах с подписью: несинхронизированные замеры могут
храниться локально. Сначала синхронизируйте данные и попробуйте обновление подписи.

На бесплатном аккаунте действуют ограничения числа активных приложений и App ID;
AltStore тоже занимает место. Если появится ошибка лимита, не создавайте новые
идентификаторы многократными попытками, проверьте установленный набор приложений.

https://developer.apple.com/help/account/basics/about-your-developer-account

Подпись и установка ещё не подтверждают корректность LiDAR, файлов и внешних ссылок:
нужен тест на физическом iPhone. При ошибке сообщите её текст, не присылая пароль.

# CEH LiDAR Scanner

Нативный iOS-компаньон для интерактивного замера CRM. RoomPlan/ARKit строит контур стены, Vision создаёт кандидаты розеток и вырезов, а результат возвращается в конкретную комнату через одноразовую сессию.

## Сборка на Mac

1. Установить Xcode и XcodeGen (`brew install xcodegen`).
2. В каталоге `ios-lidar-scanner` выполнить `xcodegen generate`.
3. Открыть `CEHLidarScanner.xcodeproj`.
4. В Signing & Capabilities выбрать Apple Developer Team и при необходимости изменить bundle identifier.
5. Собрать приложение на физический iPhone 15 Pro. Симулятор не поддерживает LiDAR.
6. После установки приложения включить запуск в production-сборке CRM: `VITE_LIDAR_SCANNER_DISTRIBUTED=true`.
7. Если приложение опубликовано в TestFlight или App Store, указать ссылку: `VITE_LIDAR_SCANNER_INSTALL_URL=https://...`.

CRM открывает приложение схемой `cehcrm-lidar://scan`. Ссылка содержит только короткоживущий одноразовый токен сканирования, а не пароль пользователя или JWT CRM.

## Ограничения первого этапа

- RoomPlan отвечает за устойчивый контур стены.
- Vision находит прямоугольные кандидаты. Они специально импортируются с пониженной уверенностью и требуют подтверждения.
- Для промышленного распознавания розеток, круглых вырезов и выводов проводов нужно обучить и добавить Core ML-модель на фотографиях реальных замеров. API и формат результата для неё уже заложены.
- Точные размеры не переносятся из LiDAR: пользователь вводит их размерными линиями в CRM.

# CEH CRM: подготовка публикации

Статус: исходники подготовлены для первой проверки сборки. Это НЕ опубликованная
и не проверенная на устройстве версия. Автоматической отправки в Apple нет.

## Что включено

- Нативная оболочка открывает https://cehcrm.ru и сохраняет данные входа в WKWebView.
- LiDAR открывается внутри приложения, с кнопкой возврата в CRM.
- На устройствах без LiDAR доступен обычный интерфейс CRM; сканер объясняет ограничение.
- Камера запрашивается только при запуске сканирования.
- Внешние ссылки передаются iOS; открытие конкретного приложения зависит от
  установленного приложения и поддержки им ссылки. Гарантии для MAX/Диска пока нет.
- Одноразовый токен сканирования принимается только для HTTPS сервера cehcrm.ru,
  ожидаемого пути сессии; перенаправления при загрузке результата запрещены.
- Workflow `iOS build check` проверяет компиляцию на macOS без сертификатов.
- После компиляции workflow запускает XCTest на доступном iPhone-симуляторе
  и сохраняет отчёт. До его фактического запуска тесты не считаются пройденными.
- Рабочая инвентаризация для политики: [PRIVACY_PREPARATION.md](PRIVACY_PREPARATION.md).

Идентификатор сохранён: `ru.cehcrm.lidar`. Его можно использовать для приложения
CEH CRM; перед первой публикацией согласуйте его с записью в Apple Developer.
Директория и схема Xcode оставлены `CEHLidarScanner` для совместимости.

## Сборка без собственного Mac

Для проверки используйте GitHub Actions / iOS build check / Run workflow после
публикации этой ветки. Этот workflow не создаёт устанавливаемый IPA и не отправляет
приложение в магазин. GitHub может тарифицировать macOS-минуты по вашему плану.

Для подписанной версии нужен Mac (в том числе арендованный) с актуальной версией
Xcode, допускаемой App Store Connect, либо отдельный настроенный CI с подписью.

На Mac:

```sh
brew install xcodegen
cd ios-lidar-scanner
xcodegen generate
open CEHLidarScanner.xcodeproj
```

В Xcode выберите свою Team в Signing & Capabilities, подключите iPhone,
проверьте приложение. Затем Product / Archive / Distribute App / App Store Connect.
Сначала распространяйте через TestFlight. Для следующей загрузки повышайте
CURRENT_PROJECT_VERSION в project.yml; для следующего релиза также MARKETING_VERSION.
Не сохраняйте сертификаты, пароли, provisioning profiles или Apple API keys в Git.

## Обязательные шаги до отправки

- Подтвердить активную регистрацию Apple Developer как физического лица или организации.
- Проверить, что целевой адрес действительно cehcrm.ru, а не другой домен компании.
- AppIcon добавлена в Assets.xcassets: сгенерированный знак «А» для «Амальгамы»,
  1024x1024 без прозрачности. Перед отправкой проверить её на устройстве.
- Указать реальный контакт поддержки и публичный URL политики конфиденциальности.
- Провести аудит App Privacy и required-reason APIs для итогового приложения,
  веб-части и зависимостей. Не заявлять «данные не собираются»: CRM хранит данные
  клиентов, контакты, фотографии, документы и финансовые записи на сервере.
- Проверить создание/удаление аккаунта. Если в приложении доступна регистрация,
  обеспечить предусмотренное правилами Apple удаление аккаунта внутри приложения;
  выход из системы не является удалением. Не удалять данные компании вместе с
  пользователем без отдельной согласованной политики.
- Создать отдельную демонстрационную компанию с вымышленными клиентами для App Review.
- Подготовить настоящие скриншоты подписанной сборки, описание и возрастной рейтинг.
- Проверить разрешения микрофона и камеры; при отказе обычная CRM должна работать.

## Проверка на iPhone перед TestFlight

1. Вход, перезапуск, выход, истечение авторизации, переключение пользователей.
2. Проекты, карточки клиентов, финансы, клавиатура и безопасные отступы экрана.
3. Прикрепление нескольких фото, PDF, открытие и возврат назад, скачивание файлов.
   Загрузка файлов, blob-ссылки, window.open и печать требуют отдельной проверки
   в WKWebView; их работоспособность в Safari не подтверждает работу в приложении.
4. MAX, Яндекс.Диск, маршрут в Яндекс.Картах с установленными приложениями и без них.
5. OAuth-подключение Яндекс.Диска с возвратом и сохранением авторизации CRM.
6. LiDAR на iPhone 15 Pro, отказ в разрешении, повторное разрешение через настройки,
   отмена сканирования, истечение токена, успешная отправка и применение схемы.
7. Офлайн-замер и повторная синхронизация. Первый запуск CRM требует интернета;
   полностью автономная загрузка оболочки пока не реализована.

Распознавание розеток пока эвристическое (Vision-прямоугольники), не полноценная
модель распознавания. Контур выбирается по наибольшей стене. Не обещать автоматические
производственные чертежи или точные размеры в описании магазина.

## Черновик описания магазина

Название: CEH CRM

Бренд: Амальгама

Контакт поддержки: i@mlapunov.ru

Подзаголовок: Проекты, клиенты и замеры

Описание: Управляйте проектами, контактами клиентов и финансовыми операциями.
Прикрепляйте фотографии замеров и работайте с интерактивными замерными листами.
На совместимых iPhone с LiDAR можно подготовить предварительный контур стены
для дальнейшей ручной проверки. Для работы необходим аккаунт CEH CRM.

Примечание для проверяющего: предоставить логин отдельного демонстрационного
аккаунта и путь «Проекты / демонстрационный проект / Замер / Дополнительно».
LiDAR необязателен для остальных функций и требует совместимого iPhone.
Не включать настоящие клиентские данные в демонстрационный аккаунт.

## Правила и обновления

Apple оценивает полезность приложения, в том числе согласно пункту 4.2:
наличие оболочки сайта само по себе не гарантирует одобрение. Подготовленные
нативные функции нужно показать в рабочем виде на проверке.

Изменения сервера не требуют новой нативной сборки сами по себе, но нельзя
использовать их для обхода проверки или существенной скрытой смены назначения.
Изменения нативного кода, разрешений и сканера выпускаются новой сборкой.

- https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds/
- https://developer.apple.com/support/offering-account-deletion-in-your-app/

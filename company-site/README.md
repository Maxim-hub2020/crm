# AMALGAMA

Интерактивный каталог душевых и зеркал на заказ в стиле консольного выбора моделей.

Раздел `/shop/` — каталог комплектующих для душевых с фильтрами, локальной
корзиной и запросом комплекта через действующий канал заявок. До утверждения
поставщика позиции показываются честно: «под заказ» и «цена по запросу».

## Локальный запуск

Сайт не требует сборки. Запустите любой статический HTTP-сервер из корня
проекта, например:

```powershell
python -m http.server 4173
```

После этого откройте `http://localhost:4173`.

## Отправка заявок

Форма отправляет JSON на `/api/site-leads` со следующими полями:

- `name`
- `phone`
- `service`
- `message`

Обработчик расположен в `notifier/` и пересылает подтверждённые заявки в MAX.

## SEO

- `robots.txt` разрешает индексацию сайта и закрывает служебный API.
- `sitemap.xml` содержит канонический адрес одностраничного сайта.
- В `index.html` настроены canonical, Open Graph и JSON-LD.
- Изображения WebP используются для быстрой загрузки; PNG сохранены как исходники.

## Размещение

Главный сайт использует `index.html`, `console.css`, `console.js`, `gallery-models.js`,
`gallery-catalog.js`, `script.js`, изображения в `assets/images/console/`, панораму
`assets/images/gallery/environment.webp` и локальную Three.js 0.186.1 в
`assets/vendor/three/`. Старые `gallery.*` и `cinematic.*` не подключаются.
Страницы `dushevye/`, `zerkala/` используют `service-details.css`.
Бывший `/mebel/` исключён из карты сайта и переводит посетителя в коллекцию.

12 ID конструкций в `gallery-catalog.js` сверены с публичным
`/api/public-calculator/config/` 04.10.2026. Каждому соответствует собственная
геометрия, количество створок и механизм в `gallery-models.js`. Новые типы,
добавленные в калькулятор в будущем, нужно моделировать и добавлять отдельно.
Четыре формы зеркал — демонстрационные варианты, размеры согласуются по проекту.
Стекло отрисовывается облегчённым прозрачным физическим материалом; зеркала
используют отражатель с панорамным окружением. Это интерактивная визуализация,
не производственный чертёж. Мебели в активной коллекции и форме заявки нет.

Управление: мышь/касание, стрелки клавиатуры, стандартный Gamepad API.
Крестовина выбирает модель; L1/R1 — категорию; правый стик вращает;
нижняя кнопка открывает двери; левая разбирает; верхняя меняет отделку;
Options открывает заявку. Физический геймпад требуется проверить отдельно:
автопроверка использует эмуляцию стандартной раскладки.

Источник общего развёртывания — папка `company-site/` репозитория
`Maxim-hub2020/crm`, ветка `codex/timeweb-production`. При каждой публикации
нужно синхронизировать туда файлы сайта: ручная загрузка только в `/opt/crm/company-site`
будет перезаписана следующим развёртыванием CRM.

Обновление только сайта: собрать и пересоздать исключительно `amalgama-site`
с параметром `--no-deps`. Не запускать общее развёртывание CRM для правок сайта.
Для сохранения уже опубликованных файлов в репозитории без запуска общего
развёртывания использовать коммит с `[skip ci]`.

Резервные копии хранить вне очищаемой папки `/opt/crm`, в `/opt/amalgama-backups/`.
Восстановленная актуальная версия сохранена там отдельно от старой версии.

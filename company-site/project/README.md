# AI-проектировщик душевых

Страница `/project/` — это диалоговый проектировщик вместо прежней формы заявки. Клиент может описать душевую, загрузить эскиз, фотографию или PDF и последовательно уточнить размеры прямо в чате.

## Что делает чат

- ведёт клиента по этапам: конфигурация, размеры, фурнитура, проверка, документы;
- принимает до трёх файлов JPG, PNG, WebP или PDF размером до 8 МБ каждый;
- хранит продолжение диалога через `previous_response_id`;
- показывает собранные параметры, недостающие данные и предварительный комплект фурнитуры;
- не открывает производственные документы, пока обязательные проверки не завершены;
- при наличии служебного MCP-токена обращается только к разрешённым инструментам калькулятора: `crm_calculator_catalog` и `crm_calculate_product`.

Эскиз клиента считается исходными данными, а не готовым производственным чертежом. Размеры стекла и совместимость фурнитуры должны быть подтверждены по правилам производства и техническим картам выбранных артикулов.

## Публичный endpoint

- `GET /api/public-production/chat/` — состояние подключения AI;
- `POST /api/public-production/chat/` — сообщение и вложения (`multipart/form-data`).

## Переменные сервера

- `OPENAI_API_KEY` — обязательный ключ AI;
- `OPENAI_CHATBOT_MODEL` — модель, по умолчанию `gpt-6.1-sol`;
- `CHATBOT_MCP_URL` — адрес MCP CEH CRM;
- `CHATBOT_MCP_TOKEN` — отдельный служебный токен с минимальными правами.

Финальный генератор PDF/DXF и выдача производственного пакета подключаются отдельным серверным этапом после строгой проверки всех входных данных.

# Проект душевой по эскизу

Публичная форма принимает размеры, эскиз или фотографии и выбранные позиции из каталога. После отправки сервер создаёт в CEH CRM:

- клиента и проект;
- лист замера с исходными данными;
- приложенные материалы;
- производственный план со статусом `needs_input` и признаком `mcp_ready`.

Эскиз клиента считается исходными данными, а не готовым производственным чертежом. До выпуска стекла технолог должен проверить фактические размеры, вертикали, уровень, ось стекла, высоту и выбранную фурнитуру.

Endpoint: `POST /api/public-production/intake/` (`multipart/form-data`).

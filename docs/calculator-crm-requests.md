# Калькулятор и заявки CRM

`calc.cehcrm.ru/api/` уже направлен на backend CRM. Отдельный API-ключ,
webhook или передача пароля между сайтами не нужны: используется существующий
вход калькулятора и его синхронизация архива КП.

После сохранения внутреннего КП с именем или телефоном клиента сервер создаёт
полноценный проект в первом статусе канбана «Заявки». До сохранения расчёт
остаётся черновиком в калькуляторе. Без имени и телефона проект не создаётся.
При отсутствии сети он появится после успешной синхронизации калькулятора.
Публичные заявки с amalgama.cehcrm.ru по-прежнему остаются в разделе «Запросы».

Из КП передаются имя, телефон, номер предложения, позиции, примечание клиента
и итоговая сумма с учётом ручной цены. Если КП содержит альтернативные варианты,
показывается минимальная цена с пометкой «От», как в архиве калькулятора.
Повторное сохранение обновляет тот же проект и не создаёт дубликат. Клиент
находится по телефону или создаётся автоматически. Данные изолированы по компании.

Открытый канбан проверяет новые проекты каждые 15 секунд и при возврате на вкладку.

В калькуляторе блок «Связать с CRM» позволяет войти логином и паролем CRM
и проверить компанию-получателя. Выбирать произвольный ID компании нельзя:
сервер всегда использует компанию авторизованного пользователя. Ссылка из блока
ведёт на канбан проектов CRM.

Удаление проекта требует подтверждения. Удаляются проект и содержимое связанного КП
из серверного архива. Остаётся только технический маркер идентификатора КП,
который не позволяет старой офлайн-копии восстановить удалённые контакты.
Существующие карточки клиентов, проекты, скачанные PDF и внешние копии не удаляются.
На других устройствах архив обновится при следующей синхронизации.

## Обновление

Миграция `0035_calculator_lead_link` выполняется обычным процессом деплоя.
Чтобы перенести также ранее сохранённые КП, после обновления backend выполните:

```sh
cd /opt/crm
docker compose -p crm --env-file .env -f docker-compose.prod.yml exec backend python manage.py backfill_calculator_projects
```

Повторный запуск не создаёт дубликатов и не возвращает удалённые заявки.
Команда обрабатывает архивы всех компаний, сохраняя их изоляцию.
